# DQ102 non-positive

**Family:** integrity · **Severity:** error · **Applies to:** all series ·
**Deterministic** (`p_error` = 1)

## What it reports

- On OHLCV bars, an open, high, low, close or vwap at or below zero.
- On every series with a volume column, a negative volume. A volume of zero is
  allowed: it is a day with no trades.
- On point series, a value at or below zero, but only when
  `integrity.positive_point_series = true`. That setting is off by default because
  rates, spreads and returns can be negative.

One violation per row, listing each offending field.

```
XYZ  2019-06-11  DQ102 error  non-positive  close is 0; low is 0  (line 7)
```

## Configuration

```toml
[integrity]
positive_point_series = false   # set true for prices, NAVs or index levels
```

A profile can set it for some series only:

```toml
[profiles.navs]
match = { kind = "point" }
integrity = { positive_point_series = true }
```

## Fix

A zero price is almost always a placeholder for "no data". Delete the row, or
re-fetch it.
