# DQ209 large-move

**Family:** price action · **Severity:** info · **Applies to:** OHLCV bars and
positive point series · **Bayesian** (`p_error` = P(an error), below 0.2) ·
**Classification:** market fact

## What it reports

A bar the price model scored (doc/checks/DQ201.md) and found probably real: an
earnings gap, a crash day, a move of a tick or two. It is the successor to
fafnir's 50% outlier rule, kept for review and hidden by default: `--show-info`
or `--min-severity info` shows it.

```
LIQ02  2020-02-10  DQ209 info  large-move  close 49.61→40.94 (×0.8252): probably a real move; P(error) = 0.02
LIQ07  2021-03-15  DQ209 info  large-move  close 0.1744→1.7602 (×10.09): the 1:10 split on file, ex 2021-03-15; P(error) = 0.04
FND01  2025-12-15  DQ209 info  large-move  close 165.61→131.02 (×0.7911): the 33.429 dividend on file, ex 2025-12-15; P(error) = <0.01
```

With `--actions`, a move a split or a cash dividend on file explains says so.

The hypotheses and evidence are in the output, as for the error checks.

## Configuration

Reported when an error is less likely than `[severity] info` (0.2). Ignore it
with `ignore = ["DQ209"]`.

## Fix

None: the data is probably right. Accept it.
