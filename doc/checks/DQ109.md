# DQ109 bad-context-row

**Family:** integrity · **Severity:** error or warn · **Applies to:** the context
files (`--actions`, `--meta`) · **Deterministic** (`p_error` = 1)

## What it reports

A row of a context file that dorq could not use. The row (or, in a metadata
file, the one field) is skipped and the run goes on: one bad row out of
thousands must not cost every other check. Only a file that cannot be read as a
whole stops the run with exit status 3 (doc/context.md).

| File | Problem | Then | Severity |
|---|---|---|---|
| `--actions` | no series, or an ex-date that is not a date | the row is skipped | error |
| `--actions` | a type other than `split` or `dividend` | the row is skipped | error |
| `--actions` | a split whose numerator or denominator is empty, zero, negative or not a number | the row is skipped | error |
| `--actions` | a dividend whose amount is empty or not a number | the row is skipped | error |
| `--meta` | no series, or a series listed a second time | the row is skipped; the first is kept | warn |
| `--meta` | a `nav_priced` that is not true or false, or a `tick_size` that is not a positive number | the field is left unset | warn |

A skipped split leaves the price model without it, so the move it explains may
be reported as DQ203 as well; that is why an actions row is an error. A skipped
metadata field costs a series no more than a profile match or its exchange tick.

A dividend of zero or less is a usable row: DQ705 reports it.

Each report is filed under the series the row names, whether or not that series
is in the input, with the file's name (not its directory) as its source and the
row's line. They come after the series' own reports, before the cross-sectional
ones. A row's ex-date, when it has one, is the report's date, so `--since` drops
a row dated before it. Profiles do not apply: a row of a context file belongs to
no series' profile, so only the global `select` and `ignore` turn DQ109 off.

```
3141  2021-03-15  DQ109 error  bad-context-row  actions.csv: numerator "0" is not a positive number; the row is skipped  (line 57)
3141  line 58  DQ109 error  bad-context-row  actions.csv: ex_date "2021-13-01" is not a date; the row is skipped
2718  line 9  DQ109 warn  bad-context-row  meta.csv: nav_priced "maybe" is not true or false; it is left unset
```

## Fix

Correct the row where it was exported from, or remove it
(`suggested_action.kind` = `fix_context_row`).
