# DQ108 out-of-bounds

**Family:** integrity · **Severity:** error · **Applies to:** any series, when
`bounds` is set · **Deterministic** (`p_error` = 1)

## What it reports

A close (a point series' value) outside the range set by `[integrity] bounds`.
No bounds are set by default, so the check reports nothing until a profile sets
them. A 10-year yield in percent lies in [−5, 25], so a value of 470 is a rate
stored in basis points or a stray print. A volatility index is never negative.

```
RAT02  2021-02-26  DQ108 error  out-of-bounds  value 470 is outside the bounds [-5, 25]  (line 3550)
```

The bounds also inform the price model on point series: a value outside them is
implausible as a real move (doc/checks/DQ201.md, "Point series"), so a bad print
there is reported as DQ201 as well.

## Configuration

```toml
[profiles.rates]
match = { kind = "point" }
price = { transform = "diff" }
integrity = { bounds = [-5, 25] }
```

`bounds` is `[low, high]`, with low below high; both ends are allowed values.

## Fix

Re-fetch the value. If it is a whole era in other units (percent stored as basis
points, a rate stored as a decimal), DQ202 reports the era and the factor.
