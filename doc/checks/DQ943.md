# DQ943 statements-missing

**Family:** statements, coverage and freshness (DQ94x) · **Severity:** warn ·
**Applies to:** statements, with `--meta` · **Deterministic**

## What it reports

A security that `--meta` expects statements for (`statements_expected`, or fafnir's
`first_quarter`), with no rows in the input. It succeeds fafnir's
`fundamentals_coverage`.

Once a statements input ends, dorq visits each `--meta` series the input did not
have, in the meta file's order, as a statements series with no rows. A bars input
visits none. The report spans the security's trading life from the coverage floor
(`[statements] coverage_floor`): from the later of its first trade and the floor,
to its last trade. A security that stopped trading before the floor is not
reported.

```
MIS01  2012-03-01..2026-10-30  DQ943 warn  statements-missing  the metadata expects statements for this security, and the input has none: it traded from 2012-03-01 to 2026-10-30
```

**Keys.** The series and the span's first day. The detail holds `from` and `to`.

## Fix

Load the vendor's statements for the security. If the vendor has none, mark it as
not expected in the security master (fafnir: the vendor master's `first_quarter`).
