# DQ915 absent-as-zero

**Family:** statements, values over time (DQ91x) · **Severity:** warn by default,
from `p_error` · **Applies to:** statements · **Bayesian** (the statement value
model, [statements.md](../statements.md#the-quarterly-structure))

## What it reports

A 0 where the item is reported in the periods either side: a value the filing did
not carry, which the vendor wrote as 0 (SF1 does; fafnir's backfill.md, probe item
6), against a real 0.

- **A real 0** is as likely as the item is 0 elsewhere in the line, plus the chance
  of its value falling to 0 or past it under the value model (DQ911): a balance
  running down to nothing reaches 0 for real, as does an item as volatile as its
  level. An item at 0 in more than a quarter of its periods, or one that takes
  both signs, is not judged.
- **An absent value** has a prior of 0.002 a value, or 0.05 for an item in
  `[statements] never_absent` (an item a reporting company always has).

The evidence:

| Evidence | For |
|---|---|
| `identity_repair` | an identity of the row fails with the 0, and the value it needs fits the periods around it |
| `quarter_sum_repair` | the year's quarters fail to sum to the year with the 0, and would with the value they need |
| `subtotals_unmoved` | at least two subtotals of the row (with `--items`) that would show the drop stayed as filed |
| `reported_at_level` | the values either side are at the item's usual level, not running down |
| `identity_holds`, `quarter_sum_holds`, `subtotal_moves` | against: the 0 fits the rest of the statement |

Real zeros (a pre-revenue company's revenue, R&D a company does not report) and
NULLs (a bank's current assets) are not reported.

```
IND26  2015-03-31 Q4 FY2015 income v1  DQ915 error  absent-as-zero  selling_general_and_administrative is 0, reported either side (expected about 2784767071): a value the filing did not carry  (line 8033)
IND13  2011-12-31 Q4 FY2011 balance_sheet v1  DQ915 warn  absent-as-zero  property_plant_equipment_net is 0, reported either side (expected about 542555757): a value the filing did not carry  (line 3671)
```

**Keys.** The version's `record_key`, with `item`. The detail holds `expected`,
`repaired` (the value an identity needs, where one does) and `views`.

**fafnir.** DQ915 succeeds `fundamentals_suspicious_zero`, which flags, at info,
a 0 between non-zero neighbours of the items in `NEVER_ZERO`. DQ915 judges every
money item, and weighs it.

## Fix

Re-fetch the period from its filing, and report the missing value to the vendor.
