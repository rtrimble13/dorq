# DQ502 carry-bar

**Family:** stale values · **Severity:** info · **Applies to:** OHLCV bars with a
volume column · **Deterministic** (`p_error` = 0, a market fact)

## What it reports

Bars with zero volume that repeat the last traded close: the feed carried the
price forward on a session with no trade. That is normal for thin names. It is
reported as info because it matters as evidence, for instance of which date a
split took effect: a carry bar holds the price before the split. A run of carry
bars is reported once.

```
THN01  2015-01-20  DQ502 info  carry-bar  1 bar with no trade carries the close 1.39 of 2015-01-16
```

The price model leaves carry bars out (doc/checks/DQ201.md, "Features").

## Fix

None needed.
